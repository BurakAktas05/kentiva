## A) 30 sn belediye reklamı (TR)

**Hedef:** Belediye yöneticisi / birim amiri
**CTA:** “90 gün ücretsiz pilot — demo@kentiva.app”

| sn | Görüntü | Ses |
|----|---------|-----|
| 0–4 | Hero / şehir + panel silüeti | “Belediye bildirimleri dağınık olmasın.” |
| 4–10 | Mobil ihbar (gerçek UI) | “Vatandaş konumlu ihbarı saniyeler içinde iletir.” |
| 10–18 | Admin kuyruk + atama | “Ekibiniz atar, SLA’yı görür, süreci kapatır.” |
| 18–24 | Harita / KPI | “Yönetim tek ekrandan operasyonu izler.” |
| 24–30 | Logo + CTA | “Kentiva. 90 gün ücretsiz pilot.” |

**Super:** KVKK uyumlu · Web + mobil · Canlı durum

## C) Kullanım kılavuzu — vatandaş (90–120 sn)

1. Uygulamayı aç / belediye seç
2. Yeni ihbar
3. Konum onayı neden gerekli (tek cümle)
4. Açıklama + fotoğraf
5. Gönder
6. İhbarlarım’dan durum

---

## D) Kullanım kılavuzu — belediye personeli (120–150 sn)

1. Panele giriş
2. Bekleyen kuyruk / SLA
3. Detay → kabul / ata
4. Durum güncelle + vatandaşa not
5. Harita / dışa aktarma (opsiyonel)
