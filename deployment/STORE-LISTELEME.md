🏆 GÜVEN PUANI SİSTEMİ

📢 BELEDİYE DUYURULARI

📊 ANKETLER

🩸 SOSYAL YARDIM PLATFORMU
Kan arama ilanları, kayıp evcil hayvan bildirimleri ve eşya bağışı ilanları ile toplumsal dayanışmaya katkı sağlayın.

🔒 GİZLİLİK VE GÜVENLİK
• KVKK uyumlu veri işleme
• Yüz ve plaka otomatik anonimleştirme
• BCrypt ile şifreleme
• Hesap silme hakkı

Kentiva — Şehrinize sahip çıkın.

## Veri Güvenliği Formu Cevapları (Google Play)

| Soru | Cevap |
|------|-------|
| Uygulama veri topluyor mu? | Evet |
| Veri şifreleniyor mu? | Evet (HTTPS/TLS transit, BCrypt at rest) |
| Kullanıcılar veri silme talep edebilir mi? | Evet (Ayarlar → Hesabı kapat) |
| **Konum** | Toplandı — İhbar oluşturma amacıyla |
| **Fotoğraflar** | Toplandı — İhbar kanıtı olarak |
| **İsim, E-posta** | Toplandı — Hesap oluşturma |
| **Telefon numarası** | Opsiyonel — Şifre sıfırlama |
| **Cihaz tanımlayıcı** | Hayır — Toplanmıyor |
| **Reklam tanımlayıcı** | Hayır — Toplanmıyor |
| Veri 3. taraflarla paylaşılıyor mu? | Evet — Belediye (ihbar işleme), altyapı sağlayıcıları |
| Veri pazarlama için kullanılıyor mu? | Hayır |
